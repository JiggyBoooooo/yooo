# SportaBiedrs — full working build

IMPORTANT: this project must be deployed/copied as a complete folder. `index.html` depends on `app.js`, `styles.css`, and the `assets/` directory. Opening or uploading only `index.html` will show the headings and empty dynamic sections (map, partner cards, shop, messages), because the application JavaScript is missing.

Use the entire ZIP contents. The application entry point is `index.html`.
